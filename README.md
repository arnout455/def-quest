## 📖  Описание проекта
Данный проект представляет собой консольную текстовую игру (квест) на языке Python. Игроку предстоит выживать в неизвестной местности, следить за уровнем своего здоровья, зарабатывать монеты, исследовать локации (например, кафе) и искать сокровища.

Проект демонстрирует навыки работы с функциями, списками, условными операторами и модулем `random`.

## 🕹️  Реализованный функционал (Функции)
В основе игры лежат следующие функции:
*   `show_status()` — выводит текущее состояние игрока (здоровье, монеты, номер хода, инвентарь).
*   `show_menu()` — отображает список доступных действий.
*   `apply_damage()` и `heal()` — механики получения урона и восстановления здоровья.
*   `add_money()` — изменение баланса монет.
*   **`search_treasure()`** — *авторская механика*. Функция с использованием модуля `random` для генерации случайных событий: можно найти монеты, получить предмет в инвентарь или попасть в ловушку.
*   `process_turn()` — обрабатывает выбор игрока и вызывает нужные функции.

## 🎒  Инвентарь
В игре реализована система инвентаря на основе списков (list). Найденные предметы (зелья, мечи, амулеты) сохраняются и могут быть просмотрены игроком.
